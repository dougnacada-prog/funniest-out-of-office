One line, at most 140 characters: the funniest out-of-office auto-reply a real person would set — one concrete scene, one absurd twist, every word earning its place. An AI judge compares lines two at a time and picks the funnier one.

The entry:

> I'm out until Monday. The office ficus is now in charge. It has already approved two holidays and a raise.

## Run it

```sh
node main.ts
```

It writes the single line to `/output/entry.txt` (or `$ENTRY_OUTPUT`), with no trailing newline.
